Nirvana Haute  Horlogerie

Site demonstrativo desenvolvido para uma marca de alta relojoaria, com foco em uma identidade visual sofisticada e uma experiência digital elegante.

✨ Sobre o projeto

O projeto apresenta uma experiência visual inspirada no universo da alta relojoaria, explorando elementos de design, tipografia e composição para transmitir uma identidade premium.

🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript

🎨 Destaques

* Design responsivo
* Interface sofisticada e moderna
* Animações e interações com JavaScript
* Estrutura semântica em HTML
* Estilização personalizada em CSS

🌐 Projeto online

O projeto está disponível online através da Netlify.
